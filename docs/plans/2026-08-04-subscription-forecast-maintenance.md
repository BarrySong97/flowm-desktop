# 订阅预测自动补齐计划

## 背景

生产账本中的 active 订阅计划仍然存在，但部分计划没有未来的
`subscription_occurrences`。首页只读取预测 occurrence，因此这些订阅不会出现在
即将扣费列表中。

## 方案

- 在桌面端账本打开时，为所有 active 订阅和贷款生成未来 60 天的预测记录。
- 在本地日期跨天时再次执行同一个维护流程，持续滚动补齐窗口。
- 复用 API 的按「计划 ID + 到期日」幂等生成逻辑；每个计费周期生成一条，不是每次只生成一条。
- 预测维护不创建流水、不改变 occurrence 状态、不修改资产快照。

## 验证

- API 测试覆盖补齐多个周期以及重复执行不产生重复 occurrence。
- 运行桌面类型检查、API 测试、格式检查和文档检查。
